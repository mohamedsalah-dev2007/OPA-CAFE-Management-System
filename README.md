# OPA CAFE - نظام إدارة المقاهي

مشروع إدارة كافيه (POS System) مصمم خصيصاً لتسهيل إدارة الطلبات والمنيو والعملاء.

## التقنيات المستخدمة:
- React.js
- CSS3
- Lucide-react (للأيقونات)

## خطوات تشغيل المشروع:
1. تأكد من تثبيت Node.js على جهازك.
2. افتح الترمينال داخل مجلد المشروع.
3. اكتب الأمر التالي لتحميل المكتبات: `npm install`
4. لتشغيل المشروع، اكتب: `npm start`


# OPA CAFE - Coffee Shop Management System

A professional POS (Point of Sale) system designed to streamline cafe operations, including order management, menu customization, and customer tracking.

## Technologies Used:
- React.js
- CSS3
- Lucide-react (for icons)

## Getting Started:
1. Ensure you have Node.js installed on your machine.
2. Open the terminal inside the project folder.
3. Run the following command to install dependencies: 
   `npm install`
4. To start the project, run: 
   `npm start`
